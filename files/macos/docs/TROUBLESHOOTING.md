# 문제 해결 (Mac)

화면 마지막에 나오는 종료 코드와 "진단 기록" 폴더(`~/Library/Logs/LLMCliInstaller/<시각>-<ID>/`)를 먼저 확인하세요.

## 종료 코드

| 코드 | 의미 | 사용자 조치 |
| --- | --- | --- |
| 0 | 성공 | 새 터미널을 열고 명령을 실행하세요. |
| 2 | 잘못된 입력 또는 옵션(변경 없음) | `--help`로 옵션을 확인하고 다시 실행하세요. |
| 10 | 지원하지 않는 macOS 또는 CPU | macOS 13 이상, Apple Silicon 또는 Intel에서 실행하세요. |
| 12 | 로그 폴더 생성 실패 | `--log-root <폴더>`로 쓸 수 있는 폴더를 지정하세요. |
| 20 | 다운로드 실패 | 인터넷 연결을 확인하고 다시 실행하세요. |
| 23 | 무결성 오류(설치기 파일 변조 또는 설치 스크립트 주소·형식 이상) | ZIP을 다시 받아 `shasum -a 256`으로 확인한 뒤 새로 풀어 실행하세요. |
| 24 | 패키지 구조 이상(`files` 폴더 없음) | ZIP 전체를 다시 풀고, 파일을 옮기거나 지우지 마세요. |
| 40 | 설치 스크립트 실패 | 진단 기록의 `native/<id>-install.log`를 확인하세요. |
| 41 | 새 터미널 필요 | 터미널을 닫고 새로 연 뒤 명령을 실행하세요. 계획 표의 "셸 설정" 줄을 확인하고 Y로 진행하면 PATH가 추가됩니다. |
| 50 | 설치 후 버전 확인 실패 | 새 터미널에서 해당 명령의 `--version`을 직접 실행해 보세요. |
| 60 | 일부만 성공 | 요약에서 실패한 CLI를 확인하고, 그것만 다시 설치하세요. |
| 70 | 사용자 취소(변경 없음) | 필요하면 다시 실행하세요. |
| 90 | 내부 오류 | `run.log`를 확인하고 문의할 때 첨부하세요(공유 전 내용 확인). |

## 더블클릭이 막힘

1. 시스템 설정 → 개인정보 보호 및 보안을 엽니다.
2. 보안 항목의 `그래도 열기`를 누릅니다.
3. 관리자 암호를 입력합니다.
4. 다시 더블클릭합니다.

가장 쉬운 방법은 터미널에서 `bash ` 뒤에 `installer-mac.command`를 끌어다 놓고 Enter를 누르는 것입니다.

## command not found

설치 직후 `codex`, `claude`, `agy`, `grok`이 "command not found"로 나오면 터미널이 아직 새 PATH를 모르는 것입니다.

1. 터미널 창을 모두 닫고 새로 엽니다.
2. 그래도 안 되면 `grep llm-cli-installer ~/.zprofile`로 표식 블록이 있는지 확인합니다.
3. 실행 파일은 `~/.local/bin`(Grok은 `~/.grok/bin`)에 있습니다. 전체 경로로 실행해 보세요.

## Grok 설치 후 agent 명령이 바뀜

Grok 설치기는 `grok` 외에 `agent` 명령도 만듭니다. 이미 다른 `agent` 명령을 쓰고 있었다면 새 터미널에서 바뀔 수 있습니다. `which agent`로 확인하세요.
