## 보안 경고 창이 뜰 때

인터넷에서 받은 ZIP을 풀면 `installer-win.bat`에도 인터넷 출처 표시가 붙어 보안 창이 뜰 수 있습니다. `Windows의 PC 보호` 창이 뜨면 `추가 정보` → `실행`을 누릅니다. `열린 파일 - 보안 경고` 창이 뜨면 `실행`을 누릅니다. 압축을 풀기 전에 ZIP 파일 오른쪽 클릭 → 속성 → `차단 해제`를 체크하면 이 창이 뜨지 않습니다. ZIP 안에서 바로 실행하지 말고 먼저 압축을 풉니다.

## 이전 기록(journal) 전달

정본 기록은 `%LOCALAPPDATA%\LLMCliInstaller\State\migration-journal.jsonl`입니다. 원본 대신 실행 로그 폴더의 `migration-journal.sanitized.jsonl` 또는 지원 ZIP을 전달하세요. 기록에는 경로 마스킹, 패키지 ID, 단계, 종료 코드만 있고 설정/인증 내용은 없습니다.

## Google 도구 선택

- `all`, `google`, `gemini`: Antigravity CLI
- `legacy-gemini`: `-AllowLegacyGemini`가 반드시 필요하며 기본 선택에 포함되지 않음

개인 Google 계정 사용자는 Antigravity를 선택하세요. 설치기는 요금제, 로그인 상태, 토큰을 조회하지 않습니다.
